# BridgeCPOS Releases

Repositório público usado exclusivamente para distribuição dos pacotes compilados do BridgeCPOS.

- `stable.json`: canal de produção.
- `pilot.json`: canal de testes.
- Pacotes: publicados como assets de GitHub Releases.
- O código-fonte permanece no repositório privado.

Uma versão pode ser suspensa imediatamente com `suspended: true` ou bloqueada em `blockedVersions`.
